# Library Management System (C++)

## Overview
A simple console-based Library Management System built using C++.

## Features
- Add books
- Issue books
- Return books
- Search books by title or author

## Compile
```bash
g++ library_management_system.cpp -o library
```

## Run
```bash
./library
```

## Output
The program demonstrates:
- adding books
- searching books
- issuing a book
- returning a book
